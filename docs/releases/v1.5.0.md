# MacVitals 1.5.0 · 应用聚合与 Docker

MacVitals 继续专注于 SSH 下随用随开的 Mac 监控。本版新增应用资源排行与 Docker 页面，无需额外 Python 运行依赖，也不引入监控数据库或后台服务。

## 应用 / 进程

- 第五页默认显示应用 CPU、内存与成员进程数，按 CPU 或内存排序后展示前 15 名。
- `v` 切换应用与进程，`n/b` 选择应用，`Enter` 展开成员，`Esc` 收起。
- 使用原生 libproc 采集 footprint 和窗口 CPU；包内 Helper 合并到应用，并用可选系统责任进程查询补充 WebKit/XPC 归属。
- 快捷键统一到底栏，保留彩色分块、小窗口滚动和简洁的运行状态。

## Docker

- 第七页展示容器状态、CPU、内存及网络/磁盘累计 I/O；支持排序、Compose 分组与项目/服务只读视图。
- 单容器启动、停止、重启、暂停和恢复均通过操作面板确认。
- 临时查看最近 80 行日志及 inspect 摘要，结果只保留在会话内存。
- 可选功能：需要 Docker CLI 和正在运行的本地引擎。支持指定 context，sudo 启动时仍用原用户访问 Docker。

## 安装 / 更新

需要 macOS 和 Python 3.9+。下载本页的源码归档并解压，在项目目录运行：

```sh
python3 -m macvitals
```

已使用 Git 克隆的用户：

```sh
git pull --ff-only
python3 -m macvitals
```

使用 uv 安装命令入口：

```sh
uv tool install --force --reinstall --from . macvitals
macvitals
```

完整功率/频率采样可用 `sudo "$(command -v macvitals)"`。源码更新后请重新安装命令并重启程序。此发行仍为 Python 源码版，不包含 Python 运行时或 DMG。

## 验证

135 项自动测试通过，覆盖原生采样、归属、排序、Docker 操作确认与降级，以及三种 TERM 的伪终端缩放和退出。本机 Apple M5 Pro 单核受控负载测得整机 5.53%，理论值 5.56%。Mac mini / OrbStack 独立测试容器完成启动、重启、停止并清理；Docker Desktop、Colima 的现场验证仍欢迎贡献。

Compose 项目/服务视图本版只读，不包含整组控制。现有 README 硬件截图来自 1.4.0。
