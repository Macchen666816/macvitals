# Security Policy

MacVitals is a local and SSH terminal monitor. It does not collect telemetry, send data to a third-party server, or persist monitoring history.

Do not report security-sensitive details in a public issue. In particular, remove passwords, private keys, tokens, personal paths, process names, command lines, hostnames, and unredacted network information from diagnostics.

For a suspected security issue, contact the repository maintainer through the private contact method listed on the GitHub profile before public disclosure. Include the affected version, macOS version, Mac model, reproduction steps, and the smallest sanitized evidence needed to verify the issue.
